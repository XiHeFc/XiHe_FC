### 1.1 五种容器，一句话规则

### 1.3 两条必须做的结构改动

**① Dock 移出视图**（当前 `#workspaceDock` 是 `#view-wave` 的子元素）
- 现象：在后处理/串口/告警页找不到 AI 与通道列表；点左栏「AI」被拽回可视化，且左栏高亮落在**可视化**（`app-core.js:262-265` 用 `navigate('visual')`，rail 高亮按 `data-nav` 判定，AI 按钮只有 `data-action`，永不亮）。
- 改法：`#workspaceDock` 提到 `.stage` 下与 `.view-stack` 并排（`.stage{display:grid;grid-template-columns:1fr auto}`）；`layout.js` 的选择器不用改。
- 验收断言：`document.querySelector('#workspaceDock').closest('.view') === null`。

**② 「引擎」一词收敛**（一个词指两个东西）
- 左栏「引擎」= 协议/帧解析配置 → **改名「协议」**，页面 `h2` 与 `<title>` 同步为「协议与帧解析」。
- 常驻管线监视 = Source→Operator→Sink 观测 → 面板标题改**「数据管线」**；命令面板条目「数据管线监视」；新增 `Ctrl+Shift+E`；状态栏文案「管线 N」，`dropped||errors` 时变红。
- 协议页页头加胶囊「管线状态 · 3 阶段/2 端点」，点击开同一面板；面板支持停靠 Dock 第三页签（诊断）。

## 2. 核心操作流程 TOP8

每行格式：**目标 / 入口 → 主路径 → 异常与中断 → 完成判据（可见证据）**。

| # | 流程 | 入口 | 主路径（要点） | 异常/中断 | 完成判据 |
|---|---|---|---|---|---|
| F1 | 接通真串口出波形 | 左栏「串口」；顶栏数据源胶囊 | 选端口 → 选波特率（即存） → 连接（**自动关仿真**） → 协议页应用预设 → 回可视化勾通道 | 无授权设备=中文说明+toast；非安全上下文提示改 localhost；**端口开但无数据**=看 `#statFrames` 不涨；协议不匹配=`#statErrors` 增长 | 胶囊显示「真实串口·波特率」+绿点；帧计数持续增长；曲线右端在走 |
| F2 | 组织视图（通道/图页/小窗/聚焦） | Dock「数据」`Alt+2`；图上右键；图页标签 | 右键勾通道 → `＋` 新建图页 → `F2` 改名 → 双击通道卡聚焦 | 最后一个图页不可关（toast 拒绝）；图页 `×` 当前**无撤销**（见 §6 P1）；切页会重置缩放 | 标签通道计数变化；曲线条数变化；`#statusInfo` 更新 |
| F3 | 后处理出结果 | 左栏「后处理」 | 勾输入 → 写公式/连线 → 预览试算 → 添加输出 → 运行并查看图表 | 表达式非法=输入框红+保留旧值；Python 桥不可用自动回退；画布环检测拒绝 | 「脚本数据」页签 +1，通道值在跳 |
| F4 | AI 生成产物并落库 | Dock「AI」`Alt+3` | 配后端 → 输入 → 确认卡逐行校验 → 应用/丢弃 | 未配后端=提示配置；5xx=“服务暂时不可用”+重试；看板类**覆盖当前活动板**并全屏 | 卡片状态「已应用」；对应区域出现新条目 |
| F5 | 自定义视图 | 三处入口（左栏＋/图页✳/AI 画笔） | 加图形块 → 选布局通道 → 生成（跑 5 帧自检）→ 落 `state.views` | 无块也无描述=红字提示；编译失败保留输入；自检不过仍可保存并标注 | 左栏「我的视图」+1，中央切到该视图并出图 |
| F6 | 看板搭建→全屏 | `Ctrl+Shift+D` | 看板下拉/新建/复制/删除 → 拖控件 → 改属性与绑定 → 方向键微调 → 保存 → 运行看板 | 未知控件保留占位；非法 JSON 修复；切换/复制/删除会**重启设计器** | 下拉出现名字；全屏有数据且 2.6s 后顶栏隐去 |
| F7 | 告警设阈值→确认 | 左栏「告警」；Dock「预警阈值」 | 填上下限（留空=该侧不报）→ 越限出条目 → 单条/全部确认 | 未设阈值不会报警（有快路径）；TTS 只在未确认时重复播报且有冷却 | 角标归零；「待处理」为 0；「累计」不退 |
| F8 | 装插件→授权 | 设置→扩展与插件→打开目录；`Ctrl+Shift+X` | 放目录 → 重载 → `pending` 列出权限（高风险默认不勾）→ 授权并启用 | `..`/跨源/符号链接逃逸直接拒绝；id 冲突保留内置；版本或权限变化回 `pending` | 状态 chip `active`；状态栏「扩展 N」+1；命令面板可搜到 |

### 3.3 三态文案（直接照抄）

**加载**
- L1 就地（按钮/小卡）：「正在加载…」+ 按钮转圈，禁用重复点击。
- L2 列表：3 行骨架，不显示"0 条"，避免被误读为空。
- L3 长任务：「正在生成视图…（约 3 秒）」+ 可取消。

**空白（三分法，禁止混用）**

| 类型 | 场景 | 文案 | 主按钮 |
|---|---|---|---|
| 首次 | 从未有过数据/配置 | 「还没有数据源。开仿真预览或连接串口后，曲线会自动出现。」 | ▷ 开仿真预览 · 连接串口 |
| 无数据 | 有配置但当前没数 | 「已连接，但 2 秒内没收到帧。检查协议头/波特率，或看串口日志。」 | 打开串口日志 · 查看协议 |
| 被过滤光 | 有数据但条件不满足 | 「当前筛选没有匹配项。已隐藏 3 条。」 | 清除筛选 |

正范例：`.ai-empty`、告警列表空态（保持）。

**错误（三分法）**
- 可重试：「加载失败：<原因>。检查网络后重试。」+「重试」
- 不可重试：「配置无效：<字段> 不合法。」+「编辑配置」
- 降级：「AI 服务暂不可用，已切换为本地规则。」+「稍后重试」（黄色，不打断）

## 4. 导航与状态

### 4.1 状态分级与归属

| 级别 | 载体 | 内容 | 规则 |
|---|---|---|---|
| 全局持久 | `xhgcs.pro.config.v1` | 通道/量程、plots、串口、views、阈值、引擎、analysis、AI 配置与最近 40 条、TTS | 改完即存；导出剔除 apiKey |
| 布局持久 | `xhgcs.layout.v3` | dockTab/dockOpen/dockWidth/viewsWidth/serialOpen/serialHeight | 210–420 区间约束 |
| 功能持久 | `xhgcs.ui.boards.v2` / `xhgcs.pipeline.params.v1` / `xhgcs.ext.state.v1` / `xhgcs.ext.config.v1` | 看板库、阶段参数、启停授权、schema 配置 | **单一写入口**，禁止别处直写 |
| 视图内（切走重置） | 内存 | 设计器选中与 undo、图页缩放、小窗当前项 | **设计器关闭前必须提示未保存**（当前无提示） |
| 页内草稿 | DOM | AI 输入框、命令面板输入 | 刷新即丢 → 需转持久化（AI 草稿） |

**补充规则**：任何"用户手动输入过、重建成本 > 5 秒"的状态，必须落在某一级持久化里。当前违反两处：AI 草稿、看板未保存改动。

### 4.2 模态统一栈（Esc 只关一层）

现状：**7 个 Esc 所有者**，全部 capture 且无 `stopPropagation`；三处已确认双关：
1. 看板叠在设计器上（两者都 capture）→ 一次 Esc 退两层；
2. 设置（z 50）里开扩展管理（z 9600）→ Esc 关掉两层；
3. 「取消」对主题无效（外观分区改了立即生效落盘）。

目标实现：`src/core/overlay-stack.ts`（约 60 行）
```ts
type Layer = { id: string; z: number; kind: 'modal'|'panel'|'popover';
  onEscape?: () => 'handled'|'close'|'ignore'; close(): void };
pushOverlay(layer): () => void;   // 返回关闭函数，自动分配 z
topOverlay(): Layer | null;
```
四条规则：① 全局唯一 Esc 监听 → 取栈顶 → `'handled'` 则 `preventDefault+stopPropagation`；② z 阶梯：popover 9000 → 老模态 9100 → 命令面板/扩展 9200 → 视图容器 9300 → 管线 9350 → 设计器 9400 → 看板 9500 → toast 9900（老 `.modal-overlay` 的 **50 必须改**）；③ 打开入栈、关闭出栈；设计器开看板时"暂停"而非入栈，退出看板回设计器选中态；④ 即改即生效的设置项，页脚用「关闭」而非「取消」，并写一行「改动即时生效」。

## 5. 视觉验收门禁（当前结论：**BLOCK**）

### 5.1 阻断项（修完才允许发版）

| # | 问题 | 证据 | 级别 |
|---|---|---|---|
| 1 | 浅色主题下命令面板几乎不可读（深底深字 **1.12:1**） | `src/ui/shell.ts:23` 写死 `rgba(24,30,40,.99)` | P0 |
| 2 | 主题/FX 由 `html[data-theme]`/`html[data-fx]` 驱动，但 `src/**` 注入的样式 **0 处**跟随这两个属性 → 切浅色/codex 后，内核面板仍是玻璃深色材质 | `src` 检索=0；CSS 侧机制存在 | P0 |
| 3 | 4 个令牌从未定义：`--ok/--accent/--fg/--fg-2`；`--ok` 回退 `#34d399` 浅底 **1.81:1** | `styles.css` 定义=0 | P1 |
| 4 | codex 覆盖清单只含 22 个旧类，7 组新界面全漏 | `styles.css:3440/3653` | P1 |
| 5 | 左右标题条底线错位 **1px**（左 y=82 / Dock y=83） | `logs/shots/main.png` 列扫描 | P1 |
| 6 | 加载态几乎全缺；空态 **7 套**实现 | `styles.css` + `src` | P1 |

### 5.2 令牌纪律（不通过判定）

四级硬编码=none：A 强调色（写死 `#6da8d2`）／B 中性色（`#0d1117`）／C 状态色（`#34d399`）／D 调色板外自造色（`#64748b`、`#94a3b8`）。唯一豁免=令牌定义块内部。
三条完整性：①`var(--x)` 必须在 `:root`+两个 FX 块都有定义；②新表面类必须同时进玻璃规则与 codex 覆盖；③`src/**` 注入样式同样受限（禁止 fallback 固化色值）。
存量：令牌块外 hex **72 处**、rgba 字面量 **155 行**、`src/ui` 16 处硬编码 `109,168,210`。

### 5.3 逐屏判据（要点）

- 活动栏：栏宽 48、工具 40×40、居中偏差 ≤0.5px；桌面版右侧 138px 内无可点元素。
- 波形：桩标两两 ≥2px、距右边界 **≥8px**（现 0–1px 贴边）；canvas 位图 = `round(CSS宽×DPR)`；空数据画布内要有占位。
- Dock：宽 280（220–420）；**tab 条 38 与左栏 36 必须同一水平线**（现差 1px）；通道卡按钮热区 ≥24×24。
- 设计器：12 列 / 行高 44 / gap 10；细胞左缘偏差 0；浅色下输入框边框 ≥3:1（现 ≈1.1:1）。
- 看板：栅格列宽与设计器偏差 ≤1px；toast（bottom 64）与退出提示（bottom 14）间距 ≥16。
- 命令面板：宽 `min(660,88vw)`、搜索框 50；浅色可读 ≥4.5:1。
- 扩展授权：7 个状态色各自可辨且 ≥4.5:1（`active` 现 1.81:1）。
- 管线：8 卡等宽等高 4 列不换行；无数据要「暂无数据」而非单个 `—`。

### 5.4 一票否决（14 条摘要）

对比度不足 · 硬编码导致跨主题/FX 失真 · 分割线偏差 >0px · 文字被裁 · 元素重叠 · 缺态（加载/空白/错误/禁用/聚焦）· 聚焦环不可见 · 画布模糊（DPR≠位图）· 基线不可复现 · 长跑视觉漂移 · 层级遮挡 · 同一语义多套实现（toast 已有 4 套）· 空态混用 · 未定义令牌上线。

## 7. 待确认（需产品拍板）
