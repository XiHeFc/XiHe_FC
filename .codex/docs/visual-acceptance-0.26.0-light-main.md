# 浅色主题主界面 · 视觉验收报告（0.26.0 / codex + light / 1600×950@2x）

> 被测：`logs/shots/elev-main-light.png`（3200×1900，DPR 2，CSS 视口 1600×950）
> 对照：`logs/shots/elev-main.png`（同构建深色）
> 判据来源：`.codex/docs/visual-acceptance-0.22.0.md`（下称 **A22**）+ `.codex/docs/ui-elevation-spec.md`（下称 **E25**）
> 实现锚点：`assets/css/styles.css`（5258 行，2026-10-27 03:19:56）、`index.html`（1279 行）、`assets/js/data.js`（`canvasColors()`）、`assets/js/views-chart.js`（`drawValueTags()`）
> 证据标注：**【实测】** 截图像素测量（±0.5px / ±1 L\*）；**【源码】** 读文件 + 层叠特异性推定；**【推算】** 由实测色值套 WCAG/L\* 公式。

## 结论：**BLOCK**

本截图可直接证明 **5 条一票否决**（§C：#1 #2 #3 #11 #14），另有 1 条由源码推定（#9）：

1. **否决 1 — 数据文字不可读**：曲线与标桩数值在白底上只有 **1.67–2.72:1**（5 条线 + 5 个数值标签全靠颜色区分）；"仿真数据"胶囊文字 4.32:1。
2. **否决 2 — 硬编码值与该主题的设计意图不符**：`canvasColors().bg = '#ffffff'` 把"凹槽"画成"白纸"，方向与层级模型相反（应比父层暗 1.5–2.8 L\*，实际亮 **+4.69**），且它占屏 **51%**，是全场最亮面。
3. **否决 3 — 同一水平基准错位**：左栏标题条底线 y=79.5，右栏 Dock 页签条底线 y=83.5 → **4px**。
4. **否决 11 — 基线不可复现**：两版截图数据不同（电压 22.0→22.3、电流 14.0→8.7、速度 25.2→31.1）+ 时钟 03:22:34。
5. **否决 14 — 同一语义多套实现**：标题/页签类条 3 套（34/38/42+44）、虚线框 2 套、复位入口 2 个。

另有 3 个直接决定用户观感、但不进否决清单的问题：

6. **数值与标题同色**：浅色下 `--heading` ≡ `--text` ≡ `#202733`；13px 汉字的墨高（12.5px）与 18px 数字的大写高（12.5px）**完全相等** → "数值"既不更大也不更亮。用户说的"信息不突出"就是这条。
7. **一屏 7 个 `--acc` 强调**（阈值 ≤1，E25 M7）→ 没有焦点。
8. **提示信息与工具按钮同权**：全屏最显眼的两个彩色块是"暂停"（实心蓝，还配 ▶）和"新增通道 +"，而主任务（看 5 个值）没有任何强调。

## E. 修正后的可观察验收现象

> 每条都写成"用户能看到什么"，括号内是可用于复核的数值。

1. **图表不再是白纸**：屏中央 51% 的区域从 `#FFFFFF` 变为 `#EDF2F9`（ΔL\* 100→95.3），四周出现 1.5–2 L\* 的"下陷感"；缩到 25% 时能看出"一块浅灰屏幕 + 5 条彩色线"，而不是"一整块白"。
2. **5 个数值一眼可读**：`22.3 / 8.7 / 177.4 / 31.1 / 55.1` 变成卡片里最深的字（`#101820`，≥12:1），名称 12px `--text`、单位 11px `--text-dim`；数字大写高从 12.5px 提到 ≥14px，与名称墨高比从 **1.00** 提到 **≥1.35**。
3. **曲线可辨**：5 条线在白底上 ≥3:1（当前 1.67–2.72），标桩文字 ≥4.5:1；色盲模拟下仍能靠形状/圆点位置对上通道。
4. **一屏一个蓝按钮**：`--acc` 元素从 7 降到 ≤1；`暂停` 变回普通工具、图标改 ⏸；顶部"仿真数据"只剩一个绿灯 + 文字，不再是描边胶囊；眼睛第一落点是数值而不是"暂停"。
5. **顶部一条线**：三栏标题条底线都落在同一 y（80），左中右三条"不同高度的横带"消失；左栏标题下没有 1px 硬线，只剩 10px 留白。
6. **右栏只剩一种浮起物**：页签条与段控件变透明（L1），全列只有 5 张白卡是 L2；"白/灰/白/白"四条色带消失；"原始数据"激活项有明显底色差（≥ΔE 6）。
7. **左栏一眼分层**：标题 11px 灰字距、组头 11px、条目 13px 深字，左轨从 5 条收敛到 2 条；选中项只有 1 个强调信号（2px 蓝条 + 白卡），不再是"白卡+蓝条+蓝图标"三重。
8. **标桩不再打架**：顶部两枚标签间距从 3px 到 ≥8px，右缘内缩 6px 不再贴框线；11px 深色数字 + 彩色圆点，`177.4 m` 不再"压"在曲线末端。
9. **字阶 4 档**：11（元信息）/13（正文、通道名）/16（页面标题）/20（数值），"小窗"下拉不再有 11.5px；同一 `.chl-val` 在任何容器都是 20px。
10. **可复现**：冻结仿真与时钟后，同构建两次截图差异 ≤0.1%，结构区 0 像素——`logs/visual/goldens` 的四组基线（dark/light × glass/codex）可以真正用于回归。
