# 0.30.1 采样可信度修复

## 行为

- 缺失通道保持上次工程值，不重复应用倍率与偏移；有效性独立记录。
- 实采与脚本结果不再按显示量程截断，保留越界峰值；内存历史附带越量程标记。
- 每个采样点保留 t、wall、valid，原值和元数据同步裁剪，不进入 localStorage 配置快照。
- 当前 UI9 的主波形和趋势控件在缺失数据/长断流处分段；游标不跨缺口插值或向采样区间外外推，读数缺失时显示破折号。
- 当前后处理的斜率、平滑时间窗改用真实样本时间，移除固定 25Hz 的换算。缺帧/断流窗口明确停止试算，避免保持值参与统计；预览小图按时间绘制并在缺口处分段。
- 清空数据时通知当前 UI 同步清理其样本缓存，避免上一轮实验残留到新一轮。
- 设备时间戳回退时开启新的内存时间段，不把倒序时间送入二分定位；原落盘文件不删除。
- 保留的 graph-engine 频谱优先使用样本时间戳推算采样率；连续不均匀采样在线性重采样后计算。缺失/重复时间/长断流拒绝计算；缺少时间戳时明确标注配置采样率。
- 频谱窗口按 radix-2 的要求取不大于请求长度的 2 的幂。

## 数值验收

`npm run test:samples` 使用真实 Chromium 和生产页面，包含 8 项检查：

1. scale=2、offset=1：原始 3 变为 7，连续缺帧仍为 7；原始 100 对应峰值 201，不被量程 [-10,10] 截断。
2. 修改 intervalMs 后，历史 t=[10,10.01,10.04,12.04] 不变。
3. 在当前 UI 的 8 秒断流区间移动真实鼠标：图例无插值读数，捕获的画布路径有分段。
4. 当前后处理页输入 200Hz、v=3t+1 的数据，斜率检出 3；注入缺帧后试算停止并给出原因。
5. 分块裁剪、主动缩窗、清空、设备时钟复位、配置持久化后，数据与元数据一致且历史不进入配置。
6. 实际 200Hz、配置 100Hz、25Hz 正弦：检出主频 25Hz。
7. 有抖动的 200Hz 采样经过重采样，25Hz 主频误差约 0.005424Hz。
8. 断流/缺失/重复时间拒绝频谱，无时间戳时明确显示配置采样率。

其他检查：当前 UI 功能回归 76/76、核心单元测试 8/8、桥接契约 26/26、旧回归中仍适用的数据链检查 4/4；TypeScript 检查与核心构建通过。最终安装版验证与包哈希另见本次交付报告。

打包版使用独立的临时用户目录，通过 CDP 在真实 Electron 主页面重跑 8 项采样检查，全部通过；版本品牌为 0.30.1，未使用用户日常配置。`test:samples` 已加入 release 链，旧门禁保持原样。

## 验证限制

当前 UI9 入口没有加载旧版 views/boot/graph UI，也没有旧回归要求的 DOM。旧 `npm run audit` 在 CSS 未引用类和 DOM 引用项失败；旧启动回归因 XHGCS_VIEWS / XHGCS_LOADER 不存在而失败。这属于当前入口与旧测试的既有不匹配，本修复没有放宽或删除门禁。

频谱属于保留的引擎模块，本次单独加载并验证，没有把它重新接入 UI9 或新增频谱页面。未进行真串口硬件压测。
