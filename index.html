01

停靠侧栏，可左右拖拽。右边缘 5px 分隔条，拖动调宽（180–420px），双击复位 240px。活动栏「可视化」/「插件」切换侧栏内容，再点当前项收起；Ctrl+B 开合；页头和侧栏头都不再放多余的收起按钮。

02

侧栏只做工作区管理。「扩展」列表回到 VS Code 式紧凑行：图标、名称、一句说明、作者，只回答“这是什么插件”；版本、描述全文、开关和重载都移进详情。行内不再放开关和 ⟳，底部两个按钮收进侧栏标题栏的 ⋯ 菜单。

03

点插件 → 工作区开详情标签。点侧栏任意插件，工作区顶部新增一个带插件图标的工作区标签（悬停显示「扩展 · 名称」，与图页并排、可关闭），内容为 VS Code 扩展详情式页面：大头标、作者、启停/重载、细节/功能/更改日志、右侧安装信息与贡献统计。停用后列表行标注“已停用”，状态栏计数同步。

04

命令面板。Ctrl+Shift+P 或顶栏命令按钮打开，输入即过滤；↑↓ 选择、Enter 执行。命令按视图 / 图页 / 通道 / 告警 / 插件 / AI 分组，插件注册的命令也出现在这里——这就是扩展性的入口。

05

数据只是工作区的一部分。主区像 VS Code 的编辑器区：装载图页，也装载插件详情；整个壳由活动栏、可拖拽侧栏、工作区标签、状态栏与命令面板组成。图表顶部图例即读数，数据视图只是插件能力中的一类。

06

分轨 / 叠加。默认分轨；需要对比时切到叠加：所有通道按各自量程归一化到 0–100%，共用一条百分比轴，便于直接比较形状与相位。

07

每页自选通道。每张图页只放你挑的通道。通道源点 ＋ 加入、− 移出，点击行聚焦；计数显示"当前页 / 全部"。单通道页不会把轨道拉满。

08

图页可增删改名。页签 ＋ 打开新建对话框（命名 + 勾选通道）；页签或图页行悬停 × 删除并确认；双击页签名改名；始终至少保留一页。

09

调试动作成套。滚轮以鼠标为锚缩放（5–120 s），拖时间轴或 Shift+拖拽平移；离开实时端出现「回到现在」，回看最多停在缓存边缘。点图例聚焦、拖拽选区测 Δt、告警标记定位；阈值线改为读取「阈值设置」，修改后即时刷新。网格、复位与导出收进页头右侧的 ⋯ 菜单；插件详情激活时整组图表工具自动隐藏。

10

AI 自定义控件。控件区标题常驻 ＋，网格底部还有通栏入口：一句话描述 → 生成中 → 预览（画布 + 自检通过）→ 保存并叠加；模板兜底。保存后的控件带 AI 徽标进入网格，点卡片开关可拖动的小窗。

11

控件箱只做资源管理。图页 / 控件 / 通道源 / 后处理四个分区可折叠，控件区默认折叠；通道筛选保留。告警是第三个侧栏视图：活动栏「告警」或状态栏「告警 1」切换侧栏内容，列表里完成定位与确认，徽标显示未确认数量；时间轴上的事件标记和阈值线保留。

12

材质、主题与可读性。面板用接缝与底色差分层的"机械面板"；深色暖炭 + 琥珀，浅色暖纸 + 锈红；数字统一等宽。本页不连接真实数据，可拖侧栏、打开插件详情并在详情里启停/重载、改告警阈值、给通道改名换色、打开后处理页、用命令面板、建页/删页/改名、增删通道、分轨/叠加、缩放平移、AI 生成控件。

13

告警是视图，不是弹窗。活动栏「告警」与控件箱 / 扩展同一种交互：切换侧栏内容、再点收起；徽标就是未确认数量。未确认 / 已确认分组，行内直接定位或确认；处理完自动归档，活动栏徽标、状态栏和上下文计数一起归零。定位会从插件详情回到图页，并把事件前后 6 秒圈出来。

14

阈值设置是工作区单例标签。告警标题栏的「阈值设置」像 VS Code 的 Settings 一样在工作区打开，只开一个；「全部确认」在没有未确认时置灰。阈值页按通道列出实时值、正常 / 越限 / 曾越限状态、量程条（斜纹标出越限区）与上下限输入；留空即不设限，校验后即时生效，图表分轨上的上限 / 下限虚线随之更新。

15

页签只说一种语言。图页、插件详情和阈值设置共享同一条工作区标签：同样的字号与活跃下划线，插件 / 设置标签带一个小图标；＋ 固定在页签末尾，不活跃标签的关闭按钮悬停才出现，不再用「告警 / 扩展」前缀和分隔线制造两种物种。告警的未确认 / 已确认分组像「图页」一样带折叠箭头，状态在确认、刷新后保留；侧栏变窄时两个动作改用短标签（阈值 / 全确认），不再只剩两个难辨图标。

16

AI 面板是右栏，不是浮层。右坞不再盖在工作区上，而是像左侧控件箱一样占一列：与工作区之间有独立分隔条，展开时 280–520px、双击复位、方向键微调；往右拖到 0 会真正收起，收起后分隔条仍留在窗口右缘，可以再拖回来。窄窗口默认收起，打开时工作区一起收缩，阈值页和图表按剩余宽度重排，不会被截断。

17

顶栏四格布局快切。双栏（侧栏 + AI）/ 仅左栏 / 仅右栏 / 专注四个小图，点一下即时唤出或收起两侧，当前组合高亮；命令面板里也有同名的四条「布局」命令。左右分隔条都能一路拖到 0：左侧栏拖到 0 后分隔条留在活动栏右侧，右坞拖到 0 后分隔条留在窗口右缘，继续拖动即可把它们拉回来，不需要先找按钮。

18

通道是可编辑资源。通道源里点名字即可原地改名，点左侧色块从六装配色里换色；图表轨道、图例、阈值卡和后处理输入会一起更新。改名不会动采样数据和图页引用。

19

后处理回到控件箱，活动栏做减法。活动栏删掉后处理图标，也删掉底部「配置」分隔线和标签；脚本与实时结果作为控件箱的第四个区（图页 / 控件 / 通道源 / 后处理），和通道源同一套行设计。先看到的仍是概要，点脚本才在工作区打开单例后处理标签；活动栏始终只高亮当前视图，工作区标签不会反向点亮活动栏。操作惯性：活动栏选视图 → 侧栏看概要 → 点条目进工作区。

20

后处理页复刻原软件。节点画布（节点库 / 画布 / 节点配置 / 运行 / 缩放 / 组件库）保留；演示稿里节点可拖、可增删，公式用当前缓冲数据实时试算。

21

后处理模式顺序：分步向导 / 快速合并 / 节点画布。分步向导是默认的四步流：① 输入通道 → ② 公式（语法检测 + 实时值与曲线预览）→ ③ 输出（标签 / 单位 / 配色就地编辑）→ ④ 确认发布。步骤完成只保留数字、不再打钩；顶部步骤可点回，页脚上一步 / 下一步，每步就地校验。快速合并是输入、公式、预览、输出同屏的全量布局；打开时进入哪个模式由设置页的「默认数据后处理模式」决定。

22

设置是工作区单例页。活动栏底部「设置」打开；数据后处理一栏提供「默认数据后处理模式」三选一：分步向导 / 快速合并 / 节点画布。修改即时保存，下次打开后处理页时生效；当前已打开的后处理页不会被强行切换，页内仍可随时手动换模式。

23

输入侧栏只有「链路」和「已保存」。链路行点进工作区做 UART 配置与开启；已保存项点开后进入工作区「保存详情」标签，上半是协议类型与帧规则，下半是保存时记录的全部通道；底部「加载此保存」与「删除」。UART 参数用紧凑的自绘下拉；顶栏暂停按钮只暂停视图，停止接收由串口开关负责。

24

页签条是一个滚动区。图页与工作区详情标签放在同一个横向滚动容器里：开满插件详情时整体滚动，不会在固定边界处把图页标签切掉半个；＋ 新建图页和右侧时间窗控件固定在滚动区外。切换图页或详情时，激活标签自动滚进视野。

25

保存 = 协议规则 + 通道名字与颜色。协议页「保存当前配置」取名保存，侧栏已保存项点开后加载；通道名字和颜色仍然只在控件箱「通道源」里修改，其他任何地方只读；控件、图页、阈值、后处理不参与保存。
